# 05 · Deep learning

**Objetivo:** entender las redes neuronales (incluida la retropropagación) y construir modelos
modernos con Keras.

**Libro:** *Hands-on ML with Scikit-Learn, Keras & TensorFlow*, 2.ª ed., caps. 10–19.

| Capítulo | Tema |
|----------|------|
| 10 | Redes neuronales con Keras |
| 11 | Entrenar redes profundas |
| 12 | Modelos personalizados con TensorFlow |
| 13 | Carga y preprocesado de datos |
| 14 | Visión por computador con CNN |
| 15 | Secuencias con RNN y CNN |
| 16 | Procesamiento de lenguaje natural (NLP) con RNN y atención |
| 17 | Autoencoders y GAN |
| 18 | Aprendizaje por refuerzo |
| 19 | Despliegue de modelos |

Antes de usar Keras programaremos una red pequeña a mano, como en
*Data Science from Scratch*, caps. 18–19.

El libro es de 2019. Los transformers y los LLM modernos se completan con material actualizado.

**Requisito:** módulo 04.
