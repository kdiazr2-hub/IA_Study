# 01 · Python sólido

**Objetivo:** pasar de "sé lo básico" a escribir Python claro y moderno, sin dudar con
funciones, clases, comprensiones, excepciones o módulos.

**Libro:** *Learning Python* (Lutz), partes II–VII. Ignora lo que sea exclusivo de Python 2,
como `print` sin paréntesis, `raw_input` o `unicode`.

## Empieza aquí

```bash
python 01_python/00_diagnostico.py
```

El diagnóstico tiene 10 funciones vacías. Complétalas y vuelve a ejecutar el archivo:
te dirá cuáles pasan. Si alguna se te atasca, no pasa nada: eso nos dice por dónde empezar.
